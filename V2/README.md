## What This Is
Complete replacement for your existing 10-file prompt system.
Built from your original files + the Instagram growth changes we discussed in this chat.

## What's Changed vs Old System
OLD:
- Default was Reel-first (static images posted as Reels = low watch time penalty)
- 5 hashtags (kept per your preference, but now structured)
- No hook overlay, no save CTA, high frequency 3-5/day

NEW v2.1:
- **Default is Carousel (4 slides)**, not Reel
  - Slide 1: Hook text overlay (under 8 words) - stops scroll
  - Slide 2: Full story
  - Slide 3: Detail / save-worthy lore
  - Slide 4: Question + soft CTA
- **Reels only when real motion exists** (zoom, timelapse, parallax)
- **Exactly 5 hashtags** per your preference:
  - Slot 1: Challenge required tag (or Primary Brand if no challenge)
  - Slot 2: Primary Brand (#VictorianGothic / #GothicHorror / #DarkFantasy)
  - Slot 3: Secondary Discovery (#SteampunkFantasy / #VictorianFantasy etc)
  - Slot 4: Subject-specific (#WeepingDryad / #FolkloreArt etc)
  - Slot 5: Always #gimpysticks (last)
  - Rotate slots 2-4, never same 5 every post
- **Caption Formula**: Hook (same as Slide 1) + 2-3 sentence micro-lore (40-100 words) + Question + Save CTA ("Save for your next story idea")
- **Alt Text** section added for Instagram SEO
- **Posting Cadence**: Max 1/day, ideal 5/week, best 7-9am / 7-10pm ET (avoid 3-5/day self-cannibalization)
- **Challenge Workflow**: If challenge REQUIRES Reel, post Reel for eligibility, then 24h later post Carousel version ("carousel version of yesterday's challenge piece") for saves

For any new prop challenge:
1. Upload these 10 files (when you want to do a prop challenge, just like before)
2. Type: /challenge [prop name] or /carousel [prop name]
3. System will output:
   - MidJourney Prompt (your default profile)
   - Carousel Plan with exact overlay text for Slide 1 and Slide 4
   - Caption with hook + question + save CTA

   - Audio (only if Reel needed)
4. In MidJourney, generate your 4 images
5. In Instagram: + > Post > select 4 images > add hook text to Slide 1 using Instagram's text tool (white serif, bottom third)
6. Paste caption + hashtags

That's it. Same lore you already write, just carousel + hook + 5 structured tags.
