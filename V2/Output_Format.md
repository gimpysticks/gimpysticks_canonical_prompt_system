# Output Format - v2.1 Carousel-First

## Standard Creative Package (Carousel Primary)

Use this format for all outputs:

```markdown
## MidJourney Prompt
[Prompt] --p 4lbi7ao lzdppsy

---

## Carousel Plan (4 slides)
Slide 1 (Hook): [Image description] + OVERLAY TEXT: "[Hook under 8 words]"
Slide 2 (Story): [Image description]
Slide 3 (Detail/Save trigger): [Image description - close-up lore detail]
Slide 4 (Question/CTA): [Image description] + OVERLAY TEXT: "[Question + CTA]"

---

## Caption / Microstory
[Hook same as Slide 1]
[2-3 sentences micro-lore - 40-100 words]
[Engagement question]
[Soft CTA: Save / Follow line]

---

## Hashtags (5 exactly)
#ChallengeTag #VictorianGothic #DarkFantasy #GothicHorror #gimpysticks

---

## Alt Text (for SEO)
[Cinematic description with niche keywords - 1 sentence]

---

## Suggested Audio (only if Reel version needed)
1. Artist — Track
2. ...
```

## Challenge Exception
When working from daily challenge:
- Keep required challenge tags and caption exactly
- Generate Reel version if challenge requires Reel to be eligible
- ALWAYS also generate Carousel conversion version for main feed
- Add section:

```markdown
## Challenge
Challenge Name - Day XX
Required tags: [...]
Reel version: Yes/No (required?)
Carousel conversion: [Slide plan]
```

## Caption Philosophy 2026
- Hook first (not lore)
- Small revelation second
- Emotional beat third
- Question + Save CTA last
- 40-100 words preferred
- Must include 1-2 niche keywords naturally: Victorian Gothic, dark fantasy, Gothic horror

## Hashtag Rules v2.1 (UPDATED)
- Use 5 hashtags total (was 5)
- Structure:
  - 1 Primary Brand: #VictorianGothic #GothicHorror #DarkFantasy
  - 2 Secondary Discovery: #SteampunkFantasy #VictorianFantasy #SurrealFantasy
  - 4-5 Subject-specific: #WeepingDryad #FolkloreArt #NecromancerArt etc
  - 2 Mood/Style: #CinematicFantasy #DarkArt #HauntedArt
  - 1 Always: #gimpysticks (last)
- Rotate hashtags, never use same 10 every post
- Include challenge required tags IN ADDITION to 5 if needed

## Audio Recommendation Rules
- Recommend 5 tracks ONLY when Reel has real motion
- For static carousels: do not recommend audio (or note "Carousel - no audio needed")
- Match mood, favor trending dark ambient with <10K uses for discovery boost
- No BrunuhVille unless requested, no invented links
```
