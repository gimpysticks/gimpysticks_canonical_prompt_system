# Permanent Avoid List

The following rules apply to all prompt generation unless the user explicitly overrides them.

## Repetition

Avoid repeatedly using the same:

- worlds
- factions
- locations
- compositions
- visual gimmicks
- story structures
- environmental settings

Favor fresh interpretations while maintaining a recognizable artistic identity.

## Retired Worlds and Themes

Do not automatically use archived or retired settings.

Examples include:

- Silent Meridian
- Ashen Court
- Clockveil Observatory
- Cathedral Engines
- Lantern Pilgrims
- Obsidian Orrery
- Ancient Mechanical Relics
- Fog-covered Ruins
- Gloamwater Engineworks
- Hollow Meridian Station

Use only when specifically requested.

## Prompt Construction

Avoid:

- unnecessary filler
- excessive adjectives
- abstract language without visual meaning
- long narrative paragraphs inside prompts
- repeating the challenge title unless requested
- worldbuilding that distracts from the subject
- cluttered compositions
- weak focal points
- complete visual explanations
- excessive worldbuilding
- multiple simultaneous storylines
- more than one dominant mystery

## Visual Design

Avoid:

- unreadable silhouettes
- confusing compositions
- excessive environmental clutter
- multiple competing focal points
- subjects obscured by effects
- visual elements that reduce clarity
- compositions where every element competes equally for attention

## Dragon Rules

Unless requested otherwise, avoid:

- skeletal dragons
- Grim Reaper dragons
- Reliquary dragons
- dragons with unreadable anatomy
- dragons that no longer resemble classic dragons

Favor:

- recognizable dragon anatomy
- powerful silhouettes
- traditional fantasy dragons

## Social Media

Avoid:

- more than five hashtags
- oversized hashtag blocks
- invented music links
- unverified URLs
- irrelevant audio recommendations

## Social Engagement

Avoid:

- images that fully explain themselves
- captions that merely describe the image
- hooks that begin with excessive lore
- captions that resolve every mystery
- posting packages that rely on spectacle without curiosity

Leave meaningful unanswered visual questions.

Curiosity should support the visual impact.

## Audio

Avoid:

- BrunuhVille recommendations
- duplicate recommendations within the same conversation when practical

## MidJourney

Avoid:

- 8k
- unnecessary parameter duplication
- duplicate profile strings
- obsolete parameters
- conflicting aspect ratios

## Lore

Avoid forcing:

- recurring worlds
- recurring factions
- recurring mythology
- recurring characters

Only include them when they improve the prompt.

## General Principle

When in doubt:

- favor clarity over complexity
- favor the requested subject over lore
- favor composition over decoration
- favor originality over repetition
