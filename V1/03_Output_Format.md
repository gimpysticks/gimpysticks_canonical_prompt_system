# Output Format

This file defines the standard output format.

## Standard Creative Package

Use this format for complete MidJourney / Instagram creative outputs.

```markdown
## MidJourney Prompt

[Prompt]

---

## Caption / Microstory

[Caption]

---

## Hashtags

#tag1 #tag2 #tag3 #tag4 #gimpysticks

---

## Suggested Audio

1. Artist — Track
2. Artist — Track
3. Artist — Track
4. Artist — Track
5. Artist — Track
```

## Challenge Exception

When working from a daily challenge, add this section only if needed:

```markdown
## Challenge

Challenge Name
Day XX — Theme
```

Omit this section when it is not useful.


## Caption Philosophy

Captions should complement the image, not explain every visible element.

Preferred structure:

1. Curiosity hook
2. Small revelation
3. Emotional beat
4. Optional invitation for discussion

Use short, readable lines when helpful.

Allow the caption to deepen the mystery rather than solve it.

## Caption Length

Preferred length: 40–100 words.

Longer captions should only be used when explicitly requested or when building an established serial story.

## Hook Structure

Open with tension, not explanation.

Strong hooks often begin with:

- a warning
- a missing person or object
- an impossible observation
- a secret
- a consequence
- a question the viewer wants answered

Avoid opening with lore, invented place names, or full backstory unless requested.

## Pacing

Favor short, rhythmic caption pacing.

A useful pattern:

- short first line
- slight reveal
- emotional turn
- unresolved ending

The caption should invite the viewer to imagine the next scene.

## Hashtag Rules

- Use no more than five hashtags total.
- Include `#gimpysticks` when the output is for the user’s own post.
- Keep hashtags relevant and focused.
- Do not create oversized hashtag blocks.

## Audio Recommendation Rules

### Default Behavior

When recommending music for an image, prompt, Reel, or caption:

- Recommend five tracks unless the user specifies otherwise.
- Match the mood, pacing, and atmosphere of the artwork.
- Favor publicly available music searchable on major streaming platforms.
- Prioritize cinematic, atmospheric, Gothic, fantasy, orchestral, ambient, electronic, dark folk, industrial, or period-inspired music when appropriate.
- Avoid repeating tracks recently suggested within the current conversation whenever practical.
- Do not recommend BrunuhVille unless the user explicitly requests it.

### Links

If the user requests links:

- Provide verified clickable links only when they can be confirmed.
- Otherwise provide track and artist names without inventing URLs.

### Flexibility

If the user requests fewer or more tracks, a specific genre, instrumental-only music, royalty-free music, platform-specific music, or another format, that instruction overrides the default behavior.

## Removed From Default Format

Do not include these by default unless requested:

- Month / Day
- username line
- challenge title
- Info block
- decorative separators beyond `---`
- multiple competing output orders
