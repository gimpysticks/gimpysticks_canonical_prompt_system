# Challenge Overlay

This file is for temporary challenge-specific rules.

Challenge rules override defaults only for the active challenge.

When the challenge ends, archive or clear this file.

Do not migrate temporary challenge rules into Core Instructions unless they become permanent.

## Challenge Overrides

A challenge may override:

- aspect ratio
- output order
- hashtags
- profile
- style
- parameters
- dates
- host requirements
- number of prompts
- posting format
- caption rules
- audio requirements
