# Profile Rules

- Use the general default for unrelated creative work.
- Use the Victorian historical default for the Late Victorian London course.
- Keep profile IDs in the listed order.
- Never duplicate, omit, reverse, or reorder IDs unless explicitly instructed.
- Use MidJourney `--p` when emitting named profile strings.
- Do not add an aspect ratio unless the user explicitly requests one.
- The selected profile persists during a conversation or challenge until explicitly changed.
